# Proposal

## Why

YouTrack TB-15 (Shopping Cart Hover Preview / Mini Cart): покупатель должен видеть содержимое корзины, не покидая текущей страницы — при наведении на иконку корзины в шапке открывается предпросмотр с товарами, ценами и общим итогом. Это снижает трение на пути к оформлению заказа и повышает конверсию в checkout. Функционал уже реализован в ветке `main` (компонент `CartPreview`), но требование нигде не зафиксировано в спеках. Расхождение TB-15 §4 («тап на мобильных → страница корзины») закрыто решением владельца продукта от 2026-11-16: текущее поведение «тап открывает закреплённый предпросмотр» подтверждено как верное, TB-15 §4 в части мобильного перехода заменён.

## What Changes

- Формализуем поведение mini-cart предпросмотра как набор требований в спеке `cart-checkout` (hover 150–200 мс, закрытие 150–250 мс, Esc, содержимое строки, клик → страница товара, пустая корзина, max-height со скроллом, доступность/focus, отсутствие сетевых запросов при наведении).
- **Мобильное поведение (зафиксировано, без изменения кода):** тап по иконке корзины на устройствах без hover открывает «закреплённый» предпросмотр (повторный тап / клик вне / Escape — закрывают, «View cart» ведёт на страницу корзины). Владелец продукта подтвердил текущую реализацию (`CartPreviewControl` + pinned-режим `CartPreviewInteraction`) как верную 2026-11-16; TB-15 §4 «тап → страница корзины» заменён. Код и существующие тесты не меняются — поведение фиксируется в спеке.
- Доработка текущего предпросмотра под спецификацию TB-15: стили popover (тень, скругления, отступы, footer «View cart» в нижней части), ширина ~380px, max-height в диапазоне 450–550px по TB-15 §3 (реализация ограничивает 520 px — внутри диапазона, оставляем), вложенность только через `header__actions`.
- Никаких изменений backend, БД, API или корзины как таковой: только состояние `CartProvider` / `useLocalizedCart` как источник данных предпросмотра.
- Тесты поведения в `frontend/tests/` (existing test zones, без создания новой test-зоны).

## Capabilities

### New Capabilities

- Нет новых capabilities: поведение относится к существующей возможности `cart-checkout`.

### Modified Capabilities

- `cart-checkout`: добавляются требования (ADDED) о предпросмотре корзины (mini-cart) в шапке — открытие/закрытие по hover, содержимое строки, пустая корзина, клик по строке → страница товара, мобильное поведение (тап → закреплённый предпросмотр), ограничения размеров и доступность. Существующие требования `cart-checkout` не меняются.

## Impact

- **Frontend (модификации):** `frontend/src/components/cart/CartPreview.tsx` и `frontend/src/lib/cart/preview-interaction.ts` — без изменений (pinned-режим `pinned`/`toggle()` остаётся: поведение подтверждено как каноническое); `frontend/src/components/store/ShopHeader.tsx` (ничего/минимум), `frontend/src/app/globals.css` (стили `.cart-preview*` под TB-15), `frontend/src/messages/sr.json` / `en.json` (клавиши `cartPreview.*` уже есть; сверить тексты TB-15), `frontend/tests/cart-preview.test.mjs` (тесты pinned-toggle сохраняются как эталон поведения; дополняются недостающие сценарии закрытия), `frontend/tests/cart.test.mjs` / `product-page.test.mjs` (регрессии корзины).
- **Зависимости/бэкенд:** нет новых пакетов; Medusa REST не вызывается при hover.
- **Design:** обязательный шаг — добавить mini-cart в Figma до реализации (см. tasks.md).
