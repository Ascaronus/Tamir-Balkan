# I18n интерфейса админки

На 11 октября 2026 `index.ts` экспортирует пустой объект: отдельный пакет переводов пользовательских страниц Dashboard здесь не зарегистрирован. Тексты расширений находятся в соответствующих компонентах, а стандартный Dashboard использует свои языковые ресурсы.

Этот каталог **не хранит переводы товаров, категорий или опций**. Они находятся в стандартном модуле Translation Medusa и читаются по `sr-RS`/`en`. Изменение языка интерфейса админки само по себе не переводит ассортимент.

- Категории: штатный **Manage translations**.
- Названия/описания товаров: native-переводы и редактор Rozetka.
- Опции: виджет **Переводы опций · SR / EN**, включая автоперевод.
- Язык покупателя и URL: код frontend, не этот каталог.

При добавлении словаря интерфейса сверяйте формат с установленной Medusa 2.13.1 и проверяйте сборку. Не переносите сюда динамические товарные тексты.
