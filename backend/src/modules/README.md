# Пользовательские модули

Сверено с кодом 11 октября 2026.

В этом каталоге нет собственных module implementations: только README. Приложение использует стандартные модули Medusa, а дополнительные review/auth/URL таблицы обслуживаются helpers из `../utils/` и создаются `setup-reviews.ts`. Native-переводы хранятся в стандартном модуле Translation. Собственных fulfillment-провайдеров нет: используются стандартные (`manual_manual`); stub `test_test` удалён из конфигурации в audit-M1 PR (2026-11).

Если здесь появится реализация, обновите этот файл её назначением, регистрацией, миграциями и проверками. Используйте API установленной Medusa 2.13.1 и проверяйте совместимость при обновлении зависимостей.
