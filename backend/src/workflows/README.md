# Пользовательские workflows

Сверено с кодом 11 октября 2026.

В `hooks/guest-cart-email.ts` зарегистрирован hook `updateCartWorkflow.cartUpdated`: по явному флагу `tamir_clear_guest_email` он очищает email и связь с гостевым customer под штатной блокировкой корзины. Данные customer не изменяются. Для аккаунтов и завершённых корзин операция запрещена. Compensation восстанавливает прежние поля при откате. Миграции не нужны; проверки — `guest-cart-email.test.cjs` и `integration-tests/http/guest-cart-email.spec.ts`. Это не означает, что бизнес-операции обходят workflows: импорт и подготовка данных вызывают `@medusajs/core-flows` из API/helpers/scripts, чтобы создавать commerce-связи штатным способом. Дополнительные SQL-транзакции используются для отзывов, кодов подтверждения, aliases и блокировок.

Если здесь появится реализация, обновите этот файл её назначением, регистрацией, миграциями и проверками. Используйте API установленной Medusa 2.13.1 и проверяйте совместимость при обновлении зависимостей.
