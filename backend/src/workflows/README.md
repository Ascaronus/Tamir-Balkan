# Пользовательские workflows

Сверено с кодом 11 октября 2026.

В этом каталоге нет собственных workflow definitions: только README. Это не означает, что бизнес-операции обходят workflows: импорт и подготовка данных вызывают `@medusajs/core-flows` из API/helpers/scripts, чтобы создавать commerce-связи штатным способом. Дополнительные SQL-транзакции используются для отзывов, кодов подтверждения, aliases и блокировок.

Если здесь появится реализация, обновите этот файл её назначением, регистрацией, миграциями и проверками. Используйте API установленной Medusa 2.13.1 и проверяйте совместимость при обновлении зависимостей.
