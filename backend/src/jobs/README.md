# Плановые задания

Сверено с кодом 11 октября 2026.

В этом каталоге нет реализованных заданий: только README. Автоматического расписания импорта Rozetka в проекте нет. Импорт запускается администратором или явно через CLI; запуск деплоя не равнозначен регулярной синхронизации ассортимента. Очистка истёкших challenge/rate записей выполняется соответствующими API helpers, а не cron из этого каталога.

Если здесь появится реализация, обновите этот файл её назначением, регистрацией, миграциями и проверками. Используйте API установленной Medusa 2.13.1 и проверяйте совместимость при обновлении зависимостей.
