# Синхронизация XML-остатков

По умолчанию ROZETKA_IMPORT_MODE=incremental: обновляются только предложения текущего файла.

Для полного снимка поставщика задайте ROZETKA_IMPORT_MODE=full и ROZETKA_UPDATE_EXISTING=true. После успешного обновления товаров и остатков отсутствующие в полном файле варианты этого источника получают нулевой остаток только на ROZETKA_STOCK_LOCATION_ID. Пустой фид отклоняется. При ошибке предыдущих этапов сверка отсутствующих предложений не запускается.

Источник записывается в metadata.rozetka_feed_source варианта как хеш полного URL фида. Не меняйте URL без проверки связи с прежним источником. Товары других источников и немаркированные старые товары не обнуляются. Первый импорт новой версией маркирует присутствующие предложения; старые предложения, отсутствующие уже в первом файле, требуют ручной проверки принадлежности источнику. Это защищает ручной ассортимент от ошибочного обнуления.

Полный импорт не является одной транзакцией. После сбоя исправьте причину и повторите импорт; сверка отсутствующих предложений выполняется последней. Запускайте один импорт за раз.
