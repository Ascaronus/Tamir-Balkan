# Стоимость доставки в карточке товара

Источник — методы доставки Medusa из админки. Фиксированные 300 RSD удалены
из текста карточки и Product JSON-LD. После изменения цены и сохранения метода
новая цена видна при следующей загрузке карточки, без пересборки фронтенда.
Обновлять отдельно текст на двух языках больше не нужно.

`GET /store/product-delivery?product_id=...` возвращает только публичные названия,
идентификаторы, суммы и валюты. Проверяются публикация товара и канал publishable
key. Профиль берётся из самого товара, склады/наборы доставки — из его доступных
каналов, регион — по Сербии. Контекст `enabled_in_store=true`, `is_return=false`,
адрес страны `rs` и вычисление цены передаются штатным модулям fulfillment/pricing
Medusa через тот же remote-query механизм, что использует Store shipping-options.
Все запросы выполняются без кэша. Админский ключ, создание корзины и миграция БД
не нужны. Самовывоз и отключённые провайдеры исключены.

- Сумма 0: **Besplatno** / **Free**.
- Одна цена (включая несколько способов с одинаковой ценой): прежняя строка
  «Dostava širom Srbije: …, u roku do 7 dana.» с актуальной суммой.
- Разные цены: список названий методов из админки с отдельными ценами.
- Нет доступной фиксированной цены, calculated-тариф или ошибка API: уточнение
  стоимости при оформлении. Отсутствие цены никогда не считается нулём.

Это публичный тариф для страны и региона, а не расчёт конкретной корзины:
промокоды, персональные условия, сумма корзины, адрес и остатки подтверждаются
существующим checkout. Срок «до 7 дней» сохранён; задача меняет только стоимость.
SEO использует те же полученные цены; при неполной оценке shippingDetails опускается.
Нужно выпускать backend и frontend вместе; старый backend без нового endpoint
покажет на новом фронтенде уточнение стоимости при оформлении.

Проверки: `product-delivery.test.cjs` — handler с подменёнными сервисами;
`product-delivery.test.mjs` — unit/component SR/EN; `product-schema.test.mjs` — SEO.
`integration-tests/http/product-delivery.spec.ts` — Medusa HTTP + изолированная БД,
региональная цена 0 вместо базовых 300, изменение на 450, отключение метода и
скрытие черновика. Локально HTTP/БД-тест не запускался: PostgreSQL/Redis недоступны.
