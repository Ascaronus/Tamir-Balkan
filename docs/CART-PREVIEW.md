# Предварительный просмотр корзины

Макет создан перед реализацией: https://www.figma.com/design/2u9V1x7faa2yieZqRP0KaF?node-id=216-3701

`CartPreview` заменяет только ссылку корзины в `ShopHeader`, сохраняя её классы, размеры и обычный переход. Mouse hover открывает окно через 180 мс, уход — закрывает через 220 мс. Keyboard focus открывает сразу; фокус внутри удерживает окно. Escape отменяет таймеры, закрывает окно и возвращает фокус на ссылку, если он был внутри. Тап пальцем или пером переключает preview без перехода на страницу; mouse click сохраняет обычный переход. На устройствах без hover click также переключает окно. Крестик и нажатие вне панели закрывают её. Touch-окно остаётся открытым при удалении строки и временной потере фокуса кнопки; переход фокуса на другой элемент вне панели закрывает окно. Внутри остаётся отдельная ссылка перехода в корзину. Смена маршрута или языка сбрасывает открытое состояние.

В окне — локализованные названия и варианты, миниатюры 60 × 75, количество, цена единицы и серверная сумма позиции. Ссылки используют текущий `product_handle`, `productPath` и `v_id`. При отсутствии handle показываются сведения без выдуманной ссылки на другой товар.

Итог — стоимость товаров, без доставки. Общие helpers `cartLineTotal` и `cartProductsTotal` сохраняют прежние fallback-правила страницы корзины и окна добавления; суммы со скидками берутся из Medusa. Нулевая стоимость не заменяется fallback-значением.

Ширина — до 380 px, высота — до 520 px и не больше доступной области экрана. Список прокручивается отдельно от footer; длинные названия переносятся. На крайне низком окне дополнительно доступна прокрутка контейнера. Появление учитывает prefers-reduced-motion.

## Данные и ошибки

Наведение, фокус и движения мыши не вызывают запросы. Preview читает текущий `CartProvider`; его идентификатор корзины и методы не заменены. Во время загрузки/изменений товаров показывается состояние загрузки. Ошибка корзины или перевода скрывает предыдущие товары и цены. Retry — явное действие пользователя через существующий refresh и повторную загрузку отображаемого текста.

`useLocalizedCartState` добавляет наблюдаемые loading/error/retry для preview. Совместимый `useLocalizedCart` сохранён. Смена количества не перезапрашивает названия; отмена старого запроса при смене языка сохранена. Backend, схема БД, зависимости и CI workflow не меняются.

## Проверки

Изучены PR #35 и TESTING-RULES. `frontend/tests/cart-preview.test.mjs` проверяет реальные контроллер/компоненты на существующем harness: таймеры, перенос указателя, фокус, Escape, touch, позиционирование, серверные суммы, обе локализации, URL варианта, empty/loading/error/retry и изменения корзины. `localized-cart.test.mjs` дополнен проверкой ошибки и retry. Старые проверки сохранены; мок в cart-confirmation адаптирован к расширенному контракту без ослабления утверждений.

Команды из frontend: `npm test`, `npm run lint -- --quiet`, `npx tsc --noEmit`, `npm run build`, `node test-support/verify-localized-routes.mjs`. Тесты выполняются на Node 20.20.2 и 24.

Это component/unit-проверки, а не браузерный E2E. Полный браузерный сценарий по правилам проекта относится к внешнему Tamir-QA-Automation: пройти мышью между иконкой и окном, Tab/Shift+Tab/Escape, обычный клик и touch-навигацию, большой список и масштаб браузера. Такой E2E в этом репозитории не дублируется.

## Проверка мобильного открытия

После исправления touch-поведения прошли 33 теста корзины, TypeScript и ESLint.
В локальном Chromium с `hasTouch`/`isMobile` проверены tap/toggle, крестик, outside tap,
удаление и последняя позиция, длинный список и переход в корзину на SR/EN. Проверены
320×568, 390×844, 768×1024 и 844×390; горизонтального переполнения нет.
Использованы реальные компоненты с тестовым CartProvider; это не проверка live Medusa
и не проверка Safari на физическом iPhone. Desktop hover и переход по клику также проверены.
