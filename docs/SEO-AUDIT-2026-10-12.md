На проверенных страницах не найдено ссылок на старые `rozetka-*` и перечисленные отсутствующие товары. Обычный HTTP-клиент не воспроизводит решение индексирующего робота и не даёт гарантии включения в индекс.

Без неё 404 остаётся корректным ответом. Корень `api.tamir.rs/` не является главной витрины; проверка API — `/health`.

## Выполненные изменения

- Общие ссылки каталога приведены к `/rs` / `/en`; пагинация и реальные фильтры сохраняются.
- Default product-card links и single-variant Offer URLs используют чистый товарный адрес. Нужные для выбора вариантов параметры сохранены.
- Пагинация вне диапазона не отдаёт пустую индексируемую страницу; ошибка API не превращается в 404.
- Добавлены регрессии для обоих языков, фильтров, выбранных вариантов, structured data и границ пагинации.
