Из 42 URL текущего sitemap 41 имеет `Submitted and indexed`; `/rs` — `Duplicate, Google chose different canonical than user`: Google выбирает `https://tamir.rs/`, хотя сайт объявляет `/rs`. Главная `/` в индексе. Изменять выбор языка посетителя или проставлять noindex на главной ради исчезновения этого исключения нельзя. Действующий входной redirect временный и зависит от языка; окончательное решение о canonical принимает Google.

Исторические 404 отсутствуют в текущем sitemap. Удалённые товары и несуществующая вторая страница каталога не должны становиться soft-404 с ответом 200 или перенаправляться на случайный товар. Empty-category noindex, redirects и canonical альтернатив — ожидаемые исключения.

Контрольные главные `/rs` и `/en` стенда исключены как дубликаты прода; один проверенный SR-товар неизвестен Google. Это не доказывает отсутствие других адресов стенда в индексе.

Публичная проверка `/rs` стенда 10 ноября подтвердила HTTP `X-Robots-Tag: noindex, nofollow, noarchive, nosnippet` и пустой sitemap; при этом HTML ещё объявлял `index, follow`. PR согласует HTML с HTTP-запретом на уровне корня и дочерних metadata и фиксирует SEO-origin на `https://tamir.rs`. Robots.txt остаётся открытым для чтения noindex.

Для ускоренного скрытия: Search Console → Удаления → Новый запрос → временно удалить все URL с префиксом `https://test.tamir.rs/`. Только стенд, НЕ `https://tamir.rs/`. Запрос временный; постоянное исключение обеспечивает noindex после повторного обхода. Публичный Search Console API не предоставляет Removals API; запрос на удаление не отправлялся. По указанию владельца работа продолжается через сервисный аккаунт, без браузера.

## Граница проверки через API

Полный отчёт «Страницы», ручные меры, отчёт о проблемах безопасности, Core Web Vitals и временные удаления не доступны через публичный Search Console API. Эти разделы не проверены. Сервисный ключ не добавляет отсутствующие методы API. Наличие ожидаемых исключений (redirect, noindex, canonical альтернатив, удалённые URL) само по себе не означает поломку сайта; отсутствие ошибок во всей панели этим аудитом не подтверждается.
